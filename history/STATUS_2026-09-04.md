## Repairs

- Selector-only portraits and poses are removed on the first real exit field, before their scanlines can cover the ladder. Teardown no longer depends on which button confirmed the choice.
- All six attack/block confirmation buttons share the same selection path. Held low-button input stays suppressed throughout confirmation.
- Sonya's internal left steps now last four frames, fixing missed steps that previously left the bootstrap character on Kung Lao. The committed live character IDs remain `11h`/`12h`.
- P1's native cursor pixels are relocated with their actual blink, border thickness, and centered number. Only P1's pixels are removed from the underlying cell, preserving P2's lower number.
- The backdrop crop is registered at column one independently of the pose origin. The sampled clear panel now matches the native background with zero pixel error and zero shift.
- Selector palettes use display-only pens beyond the hardware's 15-bit palette, preventing native gameplay palette corruption.
- The HUD name is replaced at its native image draw. This preserves the health-bar fill/frame, removes trailing native-name fragments, and uses MKII's gold letter-face colors.
- Timer expiry retains the highlighted custom fighter. Joining P2 during selection preserves P1's cell and pending choice.
- The attack-definition and hit-response tables now contain entries for the new roster IDs. Previously, an attack fetched unmapped data, used reaction index `ffh`, queued invalid callback `09e0003ah`, and entered the illegal-instruction trap at `FFA1E800`.
- Each new ID has a separately allocated native attack-definition block and reaction row. Existing roster entries are preserved. These initial blocks still use shared Liu combat routines and require character-specific tuning.
- Facing now reads each object's integer X position at `+90h`, not constant sprite metadata at `+140h`.
- Basic animations now use a semantic MKII-to-MK3 mapping. Equal numeric entries were wrong: MKII's knockdown entry 15 had been mapped to MK3's low punch. Movement, turns, blocks, punches, kicks, falls, get-up, dizzy, and victory poses now have explicit translations. The old Sonya crouching-low-kick fallback to Liu art was removed.
- The get-up timing table now has entries for both new live IDs. Previously they read `05a0h`/`1b00h` from adjacent instructions as animation delays and remained grounded for minutes. Recorded recoveries now take 18–22 frames in the exercised cases.
- Idle cadence, roundhouse/close-attack timing, and reaction-displacement tables also have independent entries for the added IDs, preserving the exact existing-index results.
- The native ground-height table now contains measured Kano/Sonya anchors (139/140 pixels). The old table read palette-pointer bytes as heights, placing Kano at Y=6968 and Sonya at Y=297 after round reset. Both now reset to the expected stage-relative position.
- Initial/alternate palette tables contain converted native MKII palette records for the new IDs. MK3's 32-bit count/implicit transparent entry is converted to MKII's 16-bit count/explicit entry zero. The CPU guard no longer suppresses every native P1 palette request.

## Test pitfalls discovered

`screen:pixel()` returns RGB in absolute screen coordinates. Older probes mistakenly treated it as a palette index and sampled visible-relative coordinates. Their visual counts and earlier stability claims are not reliable. The corrected regressions read `screen:pixels()` in visible-area coordinates. The old `mk2ks_roster_regression.lua` now emits an explicit warning.

Older two-player probes also started only P2 or supplied insufficient credits. The current tests explicitly join both players. Do not reuse those earlier results as evidence of two-player stability.

A moving clock does not prove the fighter is responsive: the v36 pre-fix recovery candidate kept the clock running while the player remained grounded. `MK2KS_ASSERT_LIFECYCLE=1` now checks recovery completion and next-round ground registration. `MK2KS_BASIC_ACTIONS=1` checks ordinary input-to-animation dispatch. `MK2KS_PROBE_NATIVE_ROSTER=1` is explicitly diagnostic: it writes the canonical roster variable once and must never be cited as proof that real selection commits that identity.
